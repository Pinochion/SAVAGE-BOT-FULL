# SAVAGE BOT — Rewrite v2

Новая версия бота для Discord на Python 3.11+ и discord.py 2.x.

## Возможности
- Настраиваемые панели управления ботом и голосовыми инструментами.
- Группы ролей: Администратор, Модератор, Checked и Family.
- Роли Tier 1 / Tier 2 / Tier 3 для сортировки списка участников (Tier 1 выше Tier 2, Tier 2 выше Tier 3; без тира — внизу).
- Ивенты `/event` и `/vzp`: все участники могут запускать набор и записываться; семейные роли упоминаются в обычном ивенте, для ВЗП — настроенная роль ВЗП.
- Контракты с набором на 15 минут, кнопками записи и автоматическим итоговым сообщением.
- Настройки тикетов и WARN через панели.
- Голосовые инструменты: перемещение участников, AFK, ограниченное напоминание включить звук, рассылка семье в ЛС.
- SQLite с миграциями и общей базой данных; поддерживается постоянная папка `DATA_DIR`.

## Локальный запуск
1. Установите Python 3.11 или новее.
2. Установите зависимости: `python -m pip install -r requirements.txt`.
3. Скопируйте `.env.example` в `.env` и укажите `DISCORD_TOKEN`. `GUILD_ID` необязателен, но полезен для быстрой синхронизации slash-команд на сервере.
4. Запустите `python main.py`.

## Bothost
- Команда запуска: `python main.py`.
- Укажите `DISCORD_TOKEN` в переменных окружения панели хостинга.
- Установите `DATA_DIR=/app/data`, чтобы SQLite-файл переживал перезапуски контейнера.
- В Discord Developer Portal включите **Server Members Intent** и **Message Content Intent**, если они требуются используемым функциям.
- Для перемещения участников у бота должны быть права **Move Members**, а его роль должна стоять выше перемещаемых ролей.

## Важно
Не публикуйте настоящий токен бота в репозитории. После замены версии проверьте права каналов и ролей на тестовом сервере.
