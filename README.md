# SAVAGE BOT — rebuild

Бот переписывается на Python 3.11 и discord.py 2.x. Ветка `rewrite/clean-rebuild` предназначена для сборки и проверки новой версии; рабочая `main` не изменяется до завершения проверки.

## Модули
- `main.py` — запуск, загрузка модулей, синхронизация slash-команд и логирование ошибок.
- `cogs/general.py` — базовые команды.
- `cogs/tickets.py` — система тикетов.
- `cogs/warns.py` — WARN.
- `cogs/admin_panel.py` — настройка групп ролей, Tier, тикетов, WARN, контрактов и реакций.
- `cogs/contracts.py` — контрактный набор на 15 минут.
- `cogs/reactions.py` — команды `/event` и `/vzp`, запись/выписка и список участников.
- `cogs/voice_admin.py` — панель голосовых каналов и рассылка участникам семьи.
- `utils/config_db.py` — общая конфигурация, миграции SQLite и приоритеты Tier.
- `utils/database.py` — совместимый интерфейс старых настроек.

## Настройка и запуск
1. Установить Python 3.11.
2. Выполнить `pip install -r requirements.txt`.
3. Установить переменные окружения `DISCORD_TOKEN` и `GUILD_ID` (последняя необязательна, но ускоряет обновление команд на тестовом сервере).
4. В Bothost для постоянного хранения базы указать `DATA_DIR=/app/data`.
5. Запустить `python main.py`.

## Текущие правила
- Все участники сервера могут запускать `/event` и `/vzp`, а также записываться и выписываться.
- Обычный `/event` упоминает роли из группы Family.
- `/vzp` упоминает настроенную роль VZP.
- Приоритет списка: Tier 1 → Tier 2 → Tier 3 → участники без Tier.
- Уровни Tier настраиваются в админ-панели; настройки сохраняются в SQLite.
- Токен бота нельзя добавлять в GitHub — только в секреты/переменные окружения.

## Важно
Новая версия ещё проходит поэтапную проверку. Перед переносом на `main` нужно проверить все компоненты в Discord-сервере и журналы Bothost.
